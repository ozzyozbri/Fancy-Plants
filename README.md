# **Fancy Plants: A Leaf of Faith (In Progress)**

Created by: Bri Osborn
Github link: https://github.com/ozzyozbri
**Time spent**: Project is still currently in progress. 

## **Project Description:**
Fancy Plants is a local Plant store located in Oneonta, AL. This is an informational site for the business showing contact information, events, and branding. Everything is made from scratch including graphics, business identity, and code. 

## **Built With:** 
1.	Photoshop: Moodboard, Graphics, Site layout
2.	Procreate: Hazel cat portrait
3.	Microsoft Word: Project Brief, Notes, and Feature layout
4.	Figma: Sitemap

## **Features:**
**Custom Designs:** Graphics are unique and created exclusively for this project (except for main logo). 
**Custom Portrait:** Hazel the shop greeter cat is a hand drawn portrait by me.  
**Location Map:** provided by Google Map tools.
**Business Identity:** Design elements, color scheme, and typography, were uniquely created for this project. 

## **Development Process:** 
I started with completing brand identity design and creating graphic assets for the business. Afterwards, I moved to creating wire frames and placements for the site. Next, I will be working on the coding portion of the project. All those steps were followed by feedback and improvements to satisfy the business’s needs.

## **Challenges and Results:** 
This is an active project that has not been completed, but so far, I have experienced an issue with time management. The website itself is very simple in nature, but created assets for the site, developing brand identity, and creating the layout have taken more time than I initially planned for. This has resulted in a “crunch time” to complete the coding portions of the site before the deadline. 

Results are to be determined.
